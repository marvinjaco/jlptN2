词汇速记

高频实词深度辨析 + 固定搭配 + 易混副词，抓住「搭配」与「语感」两个得分点。

A. 高频实词深度辨析

荒れるあれる动词
  • 天气、海面狂暴、汹涌
  • 土地、物品荒芜、破旧
  • 秩序、业绩混乱、变差
  • 皮肤粗糙
真题搭配：海・天気が荒れる（海上风浪大）——最经典高频，必考。
易错反例：鞋子磨损→すり減る；业绩下滑→落ちる／悪くなる；苹果腐烂→腐る（くさる）。
ベテラン名词
老手、经验丰富的人 —— 只能形容人。
正解：ベテランの先生（经验丰富的老师）。
不能用于：电车、钟表、餐馆（第 29 题 1/3/4 均错）。
でたらめ出鱈目ナ形/副
胡乱、瞎蒙、毫无依据。
真题：でたらめに答えた（瞎蒙着答，居然答对了）。副词用法「でたらめに＋动词」高频。
近义区分：いい加減＝敷衍马虎；でたらめ＝毫无依据、瞎来。
かわいそう可哀想ナ形
可怜的。わずかな人生（短暂坎坷的一生）→ かわいそうな人生。
排除：退屈（无聊）／おかし（奇怪）／不安（不安）。
～を欠かさないかかさない动词搭配
从不间断、不落下。
真题：どんなに忙しくても朝食と運動を欠かさない（再忙也不缺早餐和晨练）。
じたばたする动词
手忙脚乱、急得团团转。同义替换＝慌てる（あわてる）。
整句：試験前一天になっても慌ててもしかたない（就算慌张也无济于事）。

C. 易混副词对比（同义替换必考）

着々と副词
稳步地、扎实有序地（计划・工事・筹备推进，褒义）。修饰「進む・進行する・準備する」。
限制：只用于有目标的计划、项目，不能形容天气、情绪慢慢变化。
着＝落实，一步一步落实 → 稳步推进
次第にしだいに副词
渐渐地、逐步地（随时间推移，状态缓慢变化），书面感强。
三兄弟辨析：次第に（书面慢变）／だんだん（通用可互换）／次々（接连不断，不能表慢变）。
次第＝顺序 → 顺时间慢慢变化
当分 ／ しばらく同义
暂且、暂时、一段时间之内。
差别：当分（书面，常配否定「当分～ない」，中长期暂时）；しばらく（通用，可短可长，可表单小会儿）。
坑：「しばらく待ってください」不能换成当分。
むしろ／いったい／ちっとも副词
むしろ＝反倒、不如（转折递进）；いったい＝究竟；ちっとも＝一点也（后续必须接否定）。
第 32 题：小时候讨厌青椒，现在「むしろ」成了喜欢的蔬菜之一 —— 转折递进信号。

语法速记

核心句型按「接续 + 含义 + 使用场景 + 口诀」归档，重点背诵成对易混句型。

A. 核心句型卡

～わけにはいかない情理上不能
接续：动词辞書形＋。否定变体「ないわけにはいかない」＝不能不、必须。
無視して計画を進めるわけにはいかない。不能无视而推进计划（38 原题）
不是能力做不到，是道理/身份不允许。别译成"不可能"。わけ＝道理 → 按道理不能做
～ずにはいられない忍不住、情不自禁
属性：内心冲动（与上面的"道义约束"是最大对比点）。
進めずにはいられない。忍不住非要推进（38 题干扰项，语义相反）
成对必背：わけにはいかない【外部约束】 vs ずにはいられない【内心冲动】。
～てでも不惜代价也要
接续：动词て形＋でも。后半多接意志/必须类（～たい、～なければならない）。
徹夜でもレポートを終わらせないといけない。就算熬夜也要完成报告（47 题）
区别于「ても」：ても单纯"即使"；てでも带主动承担代价的语感。てでも＝不惜代价也要
～てはどうかと思います委婉提议
接续：动词て形＋。会议、学习讨论高频礼貌提案。
分析方法を取り上げてはどうかと思います。不妨把分析方法拿出来当主题（44 原题）
对比：～たらどうですか 更口语直接；てはどうかと思います 更礼貌正式。てはどうか＝提议，と思います软化
～出すと、～ほど一启动就到某程度
拆分：Vます＋出す（开始，带"一发不可收拾"语感）＋と（一…就）＋ほど（程度）。
一度食べ出すと、止まらないほど好きだ。一旦吃起来就停不下来（48 原题）
出す ≠ 始める：始める只是单纯开始；出す带"一旦启动"语感。排序题常绑定「一度～と」。
～ように言われる／注意する被吩咐 / 叮嘱
接续：动词ない形＋ように。传达指示、要求。
疲れた顔を見せないように注意された。被叮嘱不要露出疲惫表情（41 原题）
辨析：～ように（叮嘱、要求） vs ～ために（表目的，不适合叮嘱句式）。
～ておく／～ておきなさい预先做好
接续：动词て形＋おく。ておきなさい＝长辈叮嘱的命令形。
寝る前に準備をしておきなさい。睡前一定要准备好（42 原题）
题干呼应：妈妈叮嘱 + 孩子答"もう終わってるよ" → 选命令形的ておきなさい。
～させられたものだ当年被迫常做
拆解：させられる（使役被动，被迫做）＋ものだ（回忆往昔、过去常常）。
電話の応対の練習を2週間させられたものだ。当年被迫接受两周电话训练（43 原题）
标志：「入社すると…まず」回忆旧制度、往昔经历 → ものだ。

B. 其余高频句型速查

句型核心意思感情 / 使用场景
～ように注意提醒不要 / 要叮嘱、告诫
～ておく预先做好提前准备

C. 三组必背对比

わけにはいかない

外部约束、道义责任 — 按道理不能做（市长不能无视反对）

对比

ずにはいられない

内心冲动 — 忍不住要做（忍不住想推进）

～てでも

主动承担代价也要做（不惜代价）

对比

～ても

单纯的"即使"，无主动承担语感

～てはどうかと思います

礼貌正式提案（会议、讨论）

对比

～たらどうですか

口语直接建议

技巧速记

两套被真题验证的通用解题流程：排序题四步法、长句发言类五步法。

A. 句子排序题 · 四步法

抓固定搭配，锁定相邻词

「一度～出すと」「～に欠かせない」「～てでも」这类固定句型的两个成分一定挨在一起，直接锁定相对位置。

如：目標を＋達成した → 必然相邻

抓逻辑信号词

时间词（次第に、～とき）、让步（どんなに～ても、てでも）、条件（～と）是排列顺序的路标。

信号词决定先后

谓语永远在句尾

先找最后的动词，搭起句子主干，再把修饰成分往前填。

先定主干，后填修饰

通读翻译验证

排好后整句翻译一遍，逻辑不通大概率是错的。

读出声，查通顺

B. 长句场景发言类语法填空 · 五步法（38 题同类）

题型特征：长句、新闻／记者发言／观点场景，多层逻辑嵌套，选项是高度易混的 N2 句型。结构常为「背景事实 → だから／のだから → 结论（空格）」。

拆长句，圈逻辑连词

先圈「のだから／ので／から／が／けれど」，分清哪里是理由、哪里是结论。很多人错在盯着空格，忽略前面的因果前提。

给四个选项标注句型属性

不要只翻译中文，要归类：样态推测（そうにない）／许可（てもかまわない）／内心冲动（ずにはいられない）／道义约束（わけにはいかない）。

匹配说话人身份立场（出题核心）

市长、管理者 → 责任道义（わけにはいかない）；抒发个人情绪 → ずにはいられない；单纯猜测 → そうにない；许可别人 → てもかまわない。

反向排除法

先删语义完全相反的选项。38 题：前面有市民反对 → 排除「推进也没关系」「忍不住要推进」，再区分剩下的两项。

复盘归档，贴标签

把这类题单独整理，给句型贴属性标签，建立对比本。

配套训练建议

  • 专门搜集 N2 真题「記者会見・コメント・意見文」语法填空（37–42 题高频）；
  • 强制流程：圈逻辑词 → 标注句型类型 → 匹配说话人立场 → 排除；
  • 重点背三组成对句型（见语法速记 C 部分）。

读解「看文章填空」专项

以《道路のひみつ》50–54 为范本，拆解这一类"读文章填空"题的本质与通用解法。

先弄清：这类题到底考什么？

它考的不是孤立背单词，而是「文脈（上下文逻辑）」——在文章挖空处，选出能与前后文无缝衔接的词或句子。所以正确解法是"先看懂文章，再看选项"，而不是"先看选项，往里套"。

《道路のひみつ》5 个空恰好覆盖 5 种典型空格：名词/指代 语气推测 接续词 整句 句末归结

A. 四步解题流程（每题都套用）

① 通读全文抓主题：谁/什么/怎么样
② 判空格功能名词？接续？整句？句末？
③ 看前后标志圈逻辑词、找指代对象
④ 代入验证翻译＋朗读，查通顺

B. 四类空格攻克法

类型 1名词 / 指代类

做法：回看前文，找被指代、被说明的主题词。答案往往就是文章反复出现的核心名词。

50 题：前文"上班、购物、出游都受它照顾" → 点明主题就是 道路。
类型 2语气 / 推测类

做法：判断说话人的语气功能：是委婉推测、断定，还是询问。

51 题：ご存じだろう — だろう表委婉推测"想必大家都知道吧"，不是肯定也不是否定。
类型 3接续词类

做法：判断前后句的逻辑关系——追加 / 转折 / 因果 / 对比，再选对应接续词。

52 题：前讲雨天排水路面，后讲寒冷地区防结冰路面 → 并列追加，选 また（另外、还有）。
类型 4整句 / 句末归结类

做法：看与前后文的衔接、主语一致，以及句末语气（归结、义务、委婉）。

53/54 题：「工夫も考えられる」承上段举例；「支えてくれているわけだ」— わけだ表归结"正是一直在支撑我们"。

C. 《道路のひみつ》50–54 实战复盘

50承接"上班、买东西、出去玩都受它照顾"，点明这个东西就是 道路。
类型1 名词　答案 1 道路
51～だろう 是委婉推测／询问"想必大家知道吧"，不是肯定知道，也不是"不知道吧"。
类型2 语气　答案 3 ご存じだろう
52前面讲雨天排水路面，后面转寒冷地区防结冰路面，并列追加另一项工夫 →"另外、还有"。
类型3 接续　答案 1 また
53这段介绍降温路面，"也能看出／想到这样一种巧思工夫"。
类型4 整句　答案 2 工夫も考えられる
54わけだ 表归结、解释缘由：虽然肉眼看不出差别，但正是道路一直支撑我们安全生活。
类型4 句末　答案 2 支えてくれているわけだ
全文大意：默默照顾我们的其实是道路。它理所当然地存在、被很多人使用，却少有人知道其中藏着各种巧思——不易积水的路面、寒冷地区碾冰防滑的路面、能降低路面温度的设计……外观差别也许看不出，但正是它们一直支撑着我们的安全生活。
本篇考点：また＝追加列举；～だろう＝委婉推测；～わけだ＝解释归结。
5

看文章填空题 · 刻意训练方案

把"读文章填空"当成一项可拆解的技能来练，而不是靠语感碰运气。按下面五条执行，正确率能稳定提升。

先大意后空格（最关键的习惯）

拿到文章先通读一遍抓主题（这篇文章讲什么、作者态度如何），再回头看空。切忌一上来就盯着空格选项——这是这类题失分的第一大原因。

给每个空贴"功能标签"

填入前先判断这个空要的是名词／接续词／整句／句末语气中的哪一类。类型一确定，选项往往立刻少一半。

名词找指代 · 接续找逻辑 · 句末找语气

建"逻辑信号词"清单

把常见信号词做成卡片反复认：追加（また、それに）、转折（しかし、ところが、けれど）、因果（から、ので、だから）、归结（つまり、わけだ）、推测（だろう、らしい）。看到信号词就知道前后关系。

答完"代入 + 朗读"验证

把答案代回原文，把整句出声读一遍。日语靠语感，读起来别扭的十有八九是错的。这一步能救回大量"第一眼选错"的题。

错题按"归因"归类，别只记答案

每道错题标注错因：①没读懂大意 ②没判断空格类型 ③逻辑词没抓到 ④代入没验证。统计后针对最高频的错因专项突破。

推荐训练节奏

  • 专项刷：每天只做 1 篇读解的填空题（4–5 空），做完把每个空的"功能标签 + 信号词"写在旁边；
  • 还原朗读：对答案后把正确选项代回，全文朗读 2–3 遍，培养文脉语感；
  • 限时：一篇读解控制在 8–10 分钟，练"先大意后细节"的速度；
  • 复盘模板：用《道路のひみつ》5 题当模板，每道按"类型—信号—答案—验证"四栏记录，形成自己的题型库。
一句话口诀：先读全文抓大意 → 判空格类型 → 抓逻辑信号 → 代入朗读验。四步固定下来，看文章填空就能从"靠猜"变成"有据可依"。
