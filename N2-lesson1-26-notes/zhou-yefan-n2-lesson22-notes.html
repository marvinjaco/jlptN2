周业繁《新完全掌握N2语法》第22课拓展笔记

主题：可能・難易 · 区分客观可能、主观难易与说话人立场

课程说明

本笔记根据《新完全掌握日语能力考试 N2 级语法（第 2 版）》第 22 课“可能・難易”的学习者整理资料与标准 N2 语法参考提炼而成。本节主要补充课本中简略带过的辨析点、接续限制与真题易错点。

说明：研究资料中未检索到周业繁针对第 22 课“可能・難易”的视频或专栏原讲。因此，本页所有拓展点均标注为【非周业繁来源】，内容主要参考标准 N2 语法讲解与其他学习者整理的专栏。

各语法点拓展

1. ～得る／～得ない

课本已有：動詞ます形去ます＋得る／得ない，表示“能够……/不能……”。

标准N2拓展重点（【非周业繁来源】）
  • 客观可能性：侧重理论或现实上的可能/不可能，书面语色彩浓[1]。
  • 读音注意：「得る」读うる，「得ない」读えない。
  • 例句：信じ得ない出来事が起きた。／この理論は応用し得る。

そんな奇跡は二度と起こり得ない。

（那样的奇迹不可能再发生第二次。）

このデータは客観的に分析し得る。

（这些数据可以进行客观分析。）

记忆点：客观、书面 → 得る/得ない。

2. ～かねる

课本已有：動詞ます形去ます＋かねる，表示“（说话人）难以……”。

标准N2拓展重点（【非周业繁来源】）
  • 说话人立场：主语多为第一人称，表达碍于身份、情理、能力而不便做某事[1]。
  • 郑重委婉的拒绝：是商务、正式场合中常用的推脱表达。例：お引き受けしかねます。
  • 与「得ない」区别：「得ない」强调客观上不可能；「かねる」强调说话人主观上不便/难为情。

突然のお願いですので、すぐにお答えしかねます。

（因为您的请求很突然，我难以立刻答复。）

個人情報ですので、こちらでお教えしかねます。

（因为这是个人信息，恕我无法在此告知。）

记忆点：委婉拒绝 → かねる。

3. ～かねない

课本已有：動詞ます形去ます＋かねない，表示“很可能会……（不好的事）”。

标准N2拓展重点（【非周业繁来源】）
  • 负面结果的可能性：与「かねる」形态相近，但意义相反，表示“很有可能会发生某种负面结果”[1]。
  • 例句：うっかりすると、事故も起こりかねない。
  • 主语：多为事情、现象，不是说话人本身。

このまま放置すれば、大事故に発展しかねない。

（如果就这样放任不管，很可能会发展成大事故。）

彼は怒っているので、何を言い出しかねない。

（他正在气头上，很可能会说出什么话来。）

记忆点：负面可能性高 → かねない。

4. ～がたい

课本已有：動詞ます形去ます＋がたい，表示“难以……”。

标准N2拓展重点（【非周业繁来源】）
  • 主观难以忍受：强调说话人主观上“难以忍受、难以做到”，多接表示认知、情感、行为的动词，如「信じがたい」「忘れがたい」[1]。
  • 语气比「にくい」更强：带有情感色彩，不是单纯描述性质。
  • 例句：彼の言葉は信じがたい。

戦争の悲惨さは言い表しがたい。

（战争的悲惨难以用言语表达。）

昔の友人の顔は今でも忘れがたい。

（老朋友的面容至今难以忘怀。）

记忆点：情感/认知上难以接受 → がたい。

5. ～にくい／～やすい

课本已有：動詞ます形去ます＋にくい／やすい，表示“不容易……/容易……”。

标准N2拓展重点（【非周业繁来源】）
  • 表倾向，不含主客观难度判断：多用于客观描述性质、习惯，可与无生命主语搭配[1]。
  • 例句：このペンは書きやすい。／この肉は硬くて食べにくい。
  • 与「がたい」区分：「にくい」是客观描述属性；「がたい」是主观情感。

この布は汚れにくく、手入れが楽だ。

（这种布料不容易脏，很好打理。）

夏は冷房のせいで風邪を引きやすい。

（夏天因为空调很容易感冒。）

记忆点：描述事物属性/倾向 → にくい/やすい。

横向对比总结

以下汇总本课「可能・難易」相关句型的核心差异，整合「～得る／～得ない」「～かねる」「～かねない」「～がたい」「～にくい／～やすい」5个高频句型。

语法结构 接续规则 核心语义 & 语感 适用结果倾向 使用限制 标准例句
～得る／～得ない 动词ます形去ます＋得る／得ない 能够……/不能……，客观可能性，书面正式 不限好坏 侧重理论或现实上的可能/不可能；「得る」读うる，「得ない」读えない この事態は十分あり得ることだ。（这种事态是完全有可能发生的。）
～かねる 动词ます形去ます＋かねる （说话人）难以……，委婉拒绝，郑重语气 消极（拒绝/不便） 主语多为第一人称；表达碍于身份、情理而不便做某事；常用于商务正式场合 そのご意見には賛成しかねます。（您的意见我难以赞同。）
～かねない 动词ます形去ます＋かねない 很可能会……，仅用于负面结果，带有提醒、警告语气 消极/负面 只用于不好的结果；主语多为事情、现象，不是说话人本身 このままでは大事故になりかねない。（这样下去的话，很可能酿成大事故。）
～がたい 动词ます形去ます＋がたい 难以……，心理/情感上难以接受，语气强烈 消极/负面 强调主观情感上难以忍受或难以做到；多接认知、情感类动词（信じる、忘れる等） 彼の突然の辞職は信じがたい事実だ。（他突然辞职是件难以置信的事实。）
～にくい／～やすい 动词ます形去ます＋にくい／やすい 不容易……/容易……，客观描述事物属性与倾向 中性（描述属性） 多用于客观描述性质、习惯、倾向；可与无生命主语搭配；不含主客观难度判断 このペンは書きにくいので、新しいのを買いたい。（这支笔不好写，所以想买支新的。）

历年真题 / 练习题

以下题目来自 JLPT N2 历年真题或同难度练习题，用于巩固本课语法点的接续与使用场景。

この川で泳げ（　　　）？
  • 1. るか
  • 2. ないか
  • 3. られるか
  • 4. させるか
正解：1. るか（泳げるか）
解析：「泳げる」是「泳ぐ」的可能形（五段动词く结尾→ける），问这条河能不能游泳，用可能形「泳げるか」。1「るか」接在可能形词干后构成疑问，构成「泳げるか」；2「ないか」否定疑问，语义不符；3「られるか」是一段动词的可能形接法，但「泳ぐ」是五段动词；4「させるか」使役形，语义不符。
この本は字が小さくて読み（　　　）。
  • 1. にくい
  • 2. やすい
  • 3. がたい
  • 4. かねる
正解：1. にくい
解析：「にくい」表示「难以……」，侧重客观困难。字太小难以阅读。2「やすい」容易；3「がたい」难以（主观上心理上难以接受）；4「かねる」难以（委婉拒绝）。字小是客观物理困难，用「にくい」。
その話は想像し（　　　）。
  • 1. がたい
  • 2. にくい
  • 3. やすい
  • 4. かねる
正解：1. がたい
解析：正确答案是选项 1（がたい）。「～がたい」接动词ます形词干，表示心理上或主观上「难以……」，语感比「にくい」更强烈，多用于表达「即使想做也几乎不可能」的意思。句意为「那个故事难以想象」。选项2「にくい」侧重客观物理困难；选项3「やすい」意为「容易」；选项4「かねる」侧重「难以、不便（委婉拒绝）」，与「想象」搭配不当。
そのお願いは引き受け（　　　）。
  • 1. かねます
  • 2. がたい
  • 3. にくい
  • 4. やすい
正解：1. かねます
解析：正确答案是选项 1（かねます）。「～かねる」接动词ます形词干，表示从心理上感到为难、犹豫，带有委婉拒绝的语感，常用于「接受不了、做不到」等社交场合。句意为「那个请求难以接受」。选项2「がたい」侧重心理上难以接受，语感更强且偏书面；选项3「にくい」侧重客观困难；选项4「やすい」意为「容易」，语义相反。
軽く見ていると、失敗し（　　　）。
  • 1. かねない
  • 2. かねる
  • 3. がたい
  • 4. にくい
正解：1. かねない
解析：「かねない」表示「有可能……、说不定会……」，接动词ます形词干，仅用于消极、不好的结果。轻视的话有可能会失败。2「かねる」难以；3「がたい」难以（心理）；4「にくい」客观困难。
あのまま運転を続けたら、大きな事故を起こし（　　　）よ。
  • 1. かねる
  • 2. かねない
  • 3. がたい
  • 4. にくい
正解：2. かねない
解析：正确答案是选项 2（かねない）。「～かねない」接动词ます形词干，表示「很有可能……、说不定会……」，仅用于消极不好的结果，带有提醒、警告的语气。句意为「再那样继续开车的话，很可能会出大事故的哦」。选项1「かねる」表示「难以……、不便……」，委婉拒绝；选项3「がたい」表示心理上难以接受；选项4「にくい」表示客观上困难，三者均不含「有可能发生（负面）」的含义。
彼が突然会社を辞めるなんて、とても信じ（　　　）。
  • 1. にくい
  • 2. やすい
  • 3. がたい
  • 4. かねる
正解：3. がたい
解析：正确答案是选项 3（がたい）。「～がたい」接动词ます形词干，表示心理上、情感上「难以……」，语气比「にくい」更强烈。「信じがたい」是常见搭配，意为「难以置信」。选项1「にくい」侧重客观物理或操作上的困难；选项2「やすい」意为「容易」，语义相反；选项4「かねる」侧重委婉拒绝或心理上的为难，不与「信じる」搭配表「难以相信」。
この状況では、満足のいく結果は期待し（　　　）。
  • 1. やすい
  • 2. にくい
  • 3. がたい
  • 4. えない
正解：4. えない
解析：正确答案是选项 4（えない＝得ない）。「～得ない」接动词ます形词干，表示客观上「不可能……、不会有……」，「期待しえない」即「不能期待、不可能期待」。选项1「やすい」意为「容易」，语义相反；选项2「にくい」侧重客观操作上的困难；选项3「がたい」侧重心理情感上的难以接受，均不如「得ない」准确表达「客观可能性为零」的含义。
