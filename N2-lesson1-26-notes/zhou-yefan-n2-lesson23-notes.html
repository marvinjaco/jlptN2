周业繁《新完全掌握N2语法》第23课拓展笔记

主题：使役・受身・尊敬 · 聚焦格助词与句式混用陷阱

课程说明

本笔记根据《新完全掌握日语能力考试 N2 级语法（第 2 版）》第 23 课“使役・受身・尊敬”的学习者整理资料与标准 N2 语法参考提炼而成。本节主要补充课本中简略带过的辨析点、接续限制与真题易错点。

说明：研究资料中未检索到周业繁针对第 23 课“使役・受身・尊敬”的视频或专栏原讲。因此，本页所有拓展点均标注为【非周业繁来源】，内容主要参考标准 N2 语法讲解与其他学习者整理的专栏。

各语法点拓展

1. 被动句中施动者助词的选择

课本已有：被动句中，动作发出者通常用「に」，但部分动词习惯用「から」或「によって」。

标准N2拓展重点（【非周业繁来源】）
  • 一般动词：施动者用「に」。例：先生にほめられた。
  • 传递类动词：送る、届ける、渡す、与える、伝える等，施动者用「から」[1]。例：友達からプレゼントをもらわれた。
  • 创作/建造类动词：作る、書く、発明する、建てる、設計する等，施动者用「によって」表示“由……（创作/建造）”[1]。例：ピカソによって描かれた絵。

先月、父から古い時計を譲り受けた。

（上个月从父亲那里继承了一块旧手表。）

この城は戦国時代の武将によって建てられた。

（这座城堡是由战国时代的武将建造的。）

记忆点：传递类→から；创作类→によって。

2. 间接被动句的受害语感

课本已有：自动词构成的间接被动句，主语常受到不利影响。

标准N2拓展重点（【非周业繁来源】）
  • 受害/麻烦语感：如「雨に降られる」「子供に泣かれる」等，强调主语“被拖累/受影响”[1]。
  • N2真题常见：选择被动助词时，要注意是否表达“受害者”视角，而不是单纯叙述客观现象。
  • 例句：電車で隣の人に足を踏まれた。

雨に降られて、大切な書類が濡れてしまった。

（被雨淋了，重要的文件都湿了。）

電車の中で隣の人に肘を突かれて、眠れなかった。

（在电车里被旁边的人用胳膊肘挤到，没能睡着。）

记忆点：间接被动 = 我受了影响。

3. 使役句中自动词与他动词的格助词差异

课本已有：使役句根据前动词是自动词还是他动词，被使役者的助词不同。

标准N2拓展重点（【非周业繁来源】）
  • 他动词使役：使役者は／が ＋ 被使役者に ＋ 对象を ＋ 他動詞させる。例：先生は学生にレポートを書かせる。
  • 自动词使役：使役者は／が ＋ 被使役者を ＋ 自動詞させる。例：母は子供を公園で遊ばせる[1]。
  • 记忆口诀：他动词“にをさせる”、自动词“をさせる”。

先生は生徒に自由に意見を言わせた。

（老师让学生自由发表意见。）

母は幼い娘を手を離さずに歩かせた。

（母亲让年幼的女儿不松手地走路。）

记忆点：他动にをさせる、自动をさせる。

4. 使役被动形

课本已有：使役形＋被动形，表示“被迫做某事”。

标准N2拓展重点（【非周业繁来源】）
  • 主语为被迫者：表达不情愿、受强迫的语气[1]。
  • 形态变化：五段动词变为「～される」；一段动词变为「～させられる」。例：行かされる、食べさせられる。
  • 例句：上司に残業させられた。

会社の都合で、無理やり休日出勤させられた。

（因为公司的情况，被迫在休息日加班。）

親に医者を目指させられて、本当の夢を諦めた。

（被父母逼着以医生为目标，放弃了真正的梦想。）

记忆点：使役被动 = 被迫、不情愿。

5. 尊敬语与自谦语不可混用

课本已有：敬语体系分为尊敬语、自谦语、郑重语，同一句话中不能抬高己方动作。

标准N2拓展重点（【非周业繁来源】）
  • 尊敬语抬高对方：おっしゃる、いらっしゃる、なさる、くださる等[1]。
  • 自谦语压低己方：申す、いたす、参る、伺う等。
  • 主语决定敬语类型：同一句中若主语动作属于己方，不能用尊敬语形式；反之，对方动作用自谦语也不自然。例：社長がおっしゃる／私が申す。

社長がいらっしゃるまで、こちらでお待ちいたします。

（在社长到来之前，我会在这里等候。）

お客様のご意見を拝聴し、担当者にご報告いたします。

（听取客户的意见后，会向负责人汇报。）

记忆点：对方抬高、自己压低，不可混。

横向对比总结

以下汇总本课「使役・受身・尊敬」相关语法要点的核心差异，整合「被动句施动者助词（に／から／によって）」「間接受身」「使役句助词差异」「使役受身形」「尊敬・謙譲使い分け」5个核心要点。

语法结构 接续规则 核心语义 & 语感 适用结果倾向 使用限制 标准例句
被动句施动者助词 一般动作：に；传递类：から；创作建造类：によって 被动句中动作发出者的助词选择，因动词类型而异 中性 に用于一般直接被动；から用于送る/届ける/渡す等传递类动词；によって用于作る/建てる/書く等创作类动词 このお寺は有名な和尚によって建てられた。（这座寺庙是由著名的僧人建造的。）
間接受身 自动词＋られる（被动形） 间接受害被动，主语因某事而受影响、添麻烦 消极/负面（受害） 由自动词构成；强调主语"被拖累/受影响"的受害视角 昨日雨に降られて風邪を引いた。（昨天被雨淋了，感冒了。）
使役句助词差异 他动词使役：～に～を～させる；自动词使役：～を～させる 让某人做某事，使役者为主语，被使役者因动词自他性而助词不同 中性 他动词使役用「に」表被使役者、「を」表对象；自动词使役用「を」表被使役者 先生は学生に本を読ませた。（老师让学生读书。）
使役受身形 五段：～される；一段：～させられる 被迫做某事，表达不情愿、受强迫的语气 消极/负面 主语为被迫者；五段动词约音为「～される」；一段动词为「～させられる」 子供のころ、嫌いなピアノを毎日練習させられた。（小时候被迫每天练讨厌的钢琴。）
尊敬・謙譲使い分け 尊敬：お／ご＋…になる；謙譲：お／ご＋…する 尊敬语抬高对方动作；自谦语压低己方动作 中性（礼貌表达） 同一句中尊敬语与自谦语不可混用；主语决定敬语类型，对方动作用尊敬、己方动作用自谦 社長がお戻りになりました。／私がご案内します。（社长回来了。/我来为您带路。）

分语法拓展例句

① 被动句施动者助词选择

この小説は夏目漱石によって書かれた。

（这部小说是夏目漱石写的。）

私は小学校の先生から多くのことを教えられた。

（我从小学老师那里学到了很多东西。）

② 間接受身

夜中に隣の犬に吠えられて、全然眠れなかった。

（半夜被邻居家的狗叫，完全没睡着。）

急な雨に降られて、傘を持っていなかったのでびしょ濡れになった。

（被突如其来的雨淋了，因为没带伞所以全身湿透了。）

③ 使役句助词差异

母は妹に野菜をたくさん食べさせた。

（妈妈让妹妹吃了很多蔬菜。）

父は息子を近くの店に行かせた。

（爸爸让儿子去了附近的商店。）

④ 使役受身形

会社の飲み会で、上司に無理やりお酒を飲まされた。

（在公司聚餐上，被上司硬逼着喝酒。）

学生時代、毎朝早く起こされてランニングさせられた。

（学生时代，每天早上被叫起来被迫跑步。）

⑤ 尊敬・謙譲使い分け

社長が来週の会議にご出席になります。

（社长将出席下周的会议。）

私がその件についてご説明いたします。

（我来为您说明那件事。）

快速区分记忆要点
  • 一般动作に、传递类から、创作类によって → 被动句施动者助词
  • 自动词被动，强调受害添麻烦 → 間接受身
  • 他动词使役に+を、自动词使役用を → 使役句助词差异
  • 被迫不情愿，五段约音される → 使役受身形
  • 对方动作用尊敬、己方动作用自谦 → 尊敬・謙譲使い分け

历年真题 / 练习题

以下题目来自 JLPT N2 历年真题或同难度练习题，用于巩固本课语法点的接续与使用场景。

社長がおっしゃ（　　　）ことを忘れないでください。
  • 1. せた
  • 2. れた
  • 3. られた
  • 4. た
4. た（おっしゃった）
解析：「おっしゃる」是「言う」的尊敬语，属于五段动词。其过去式为「おっしゃった」（く→っ）。社长说的话，用尊敬语过去式。1「られた」变成「おっしゃられた」是被动形，不表尊敬过去；2「させた」使役；3「れた」非标准。
先生に指導して（　　　）、感謝している。
  • 1. いただいて
  • 2. もらって
  • 3. くれて
  • 4. あげて
正解：1. いただいて
解析：正确答案是选项 1（いただいて）。「～ていただく」是「てもらう」的自谦语表达，表示「承蒙某人（为自己）做某事」，主语是说话人，动作执行者是「先生」。句意为「承蒙老师指导，非常感谢」。选项2「もらって」为普通表达，缺乏自谦语感；选项3「くれて」意为「给我做」但敬语程度不够，对老师不够礼貌；选项4「あげて」意为「我为别人做」，方向相反。
こちらに署名していただけ（　　　）か。
  • 1. ます
  • 2. ません
  • 3. たい
  • 4. る
正解：1. ます
解析：正确答案是选项 1（ます）。本题考查「いただく」的可能形敬体。「いただけますか」是「いただく」的可能形「いただける」的敬体疑问形式，用于委婉地请求对方做某事，意为「能否请您……？」。句意为「能否请您在这里签字？」。选项2「ません」构成「いただけませんか」也是委婉请求，但语气更谦遂，考试中常见标准答案为「いただけますか」；选项3「たい」变为「いただきたい」可表示愿望但不构成疑问请求；选项4「る」接续不正确。
この本は有名な作家（　　　）書かれた。
  • 1. に
  • 2. によって
  • 3. から
  • 4. で
正解：2. によって
解析：正确答案是选项 2（によって）。被动句中，创作、建造、设计类动词（書く、建てる、設計する等）的施动者用「によって」，强调「由……（创作/建造）」。选项1「に」用于直接被动，动作直接作用于主语；选项3「から」用于授受、传递类动词的被动（如「もらう」「渡す」）；选项4「で」表手段、材料，不表施动者。
昨日、帰る途中で雨に（　　　）、びしょ濡れになった。
  • 1. 降って
  • 2. 降らせて
  • 3. 降られて
  • 4. 降れて
正解：3. 降られて
解析：正确答案是选项 3（降られて）。这是间接被动句（受害被动），自动词「降る」变为被动形「降られる」，表示主语因下雨而受害、添麻烦。选项1「降って」是主动て形；选项2「降らせて」是使役形（让……下雨）；选项4「降れて」是可能形，均不含「受害」的语感。
父は子供（　　　）公園で走らせた。
  • 1. に
  • 2. を
  • 3. が
  • 4. へ
正解：2. を
解析：正确答案是选项 2（を）。自动词使役句中，被使役者（动作实际执行者）用助词「を」。「走る」是自动词，因此为「子供を走らせた」（让孩子跑）。选项1「に」用于他动词使役句中表示被使役者（例：子供に本を読ませる）；选项3「が」表主语；选项4「へ」表方向。
子供のころ、嫌いな野菜を（　　　）記憶がある。
  • 1. 食べて
  • 2. 食べさせた
  • 3. 食べさせられた
  • 4. 食べられた
正解：3. 食べさせられた
解析：正确答案是选项 3（食べさせられた）。这是使役被动形（させられる形），表示「被迫做某事」，带有不情愿、被迫的语感。一段动词「食べる」的使役形是「食べさせる」，其被动形即「食べさせられる」。选项1「食べて」主动形；选项2「食べさせた」使役形（让别人吃）；选项4「食べられた」单纯被动，表「被吃」，语义不通。
「荷物は、私が（　　　）。」
  • 1. お届けになります
  • 2. 届けられます
  • 3. お届けです
  • 4. お届けします
正解：4. お届けします
解析：正确答案是选项 4（お届けします）。自己做的动作用自谦语「お＋动词ます形＋する」。「お届けします」是「届けます」的自谦语，表示「我来送（给您）」。选项1「お届けになります」是尊敬语，用于对方的动作；选项2「届けられます」是被动或可能形，不含自谦含义；选项3「お届けです」不是正确的自谦动词形式。
